# Archive

Superseded material, kept because deleting engineering history is worse
than keeping it clearly labelled.

**Nothing in here is a current claim.** Numbers, file paths, test counts
and architecture descriptions in these documents describe earlier states
of the repository. The current versions live in:

- [README.md](../../README.md) — the project, and every number it quotes
- [docs/architecture/](../architecture/) — the diagrams and the trust model
- [docs/generated/truth.json](../generated/truth.json) — the evidence file

| Directory | What it holds |
|---|---|
| `build-log/` | Day-by-day development log, superseded reports and checklists |
| `old-diagrams/` | The `.mmd` diagram sources replaced by the current architecture docs |
| `scripts/` | One-off scripts from the build that no longer run against current paths |
| `ARCHITECTURE-v1.md`, `blueprint.md`, `PITCH_SCRIPT-v1.md` | Earlier drafts |
| `TRUTH_NUMBERS-v1.json` | The hand-maintained metrics file replaced by the generated one |
